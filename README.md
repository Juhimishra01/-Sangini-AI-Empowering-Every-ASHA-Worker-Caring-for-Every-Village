# Sangini AI 🏥

An AI-powered digital healthcare assistant for ASHA workers in rural India.

## Built with
- React 18 + TypeScript + Tailwind CSS
- Firebase Authentication + Firestore
- Gemini AI (health assistant + OCR)
- Vercel deployment

## Features
- Real Firebase phone/email authentication
- Patient records with Firestore database
- AI Health Assistant powered by Gemini
- Village analytics dashboard with AI insights
- Gemini Vision OCR for prescription scanning
